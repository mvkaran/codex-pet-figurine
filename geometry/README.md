# Geometry-only 3MFs

These files use millimeters and include color regions. Set up your printer, materials and supports in your slicer, or use the prepared [Bambu projects](../print-projects/).

| File | Contents |
| --- | --- |
| [figurine.3mf](figurine.3mf) | Four-color figurine, upright with feet at Z=0 |
| [base-mvkaran.3mf](base-mvkaran.3mf) | Base with pegs and colored lettering |
| [base-plain.3mf](base-plain.3mf) | Plain base with the same pegs |
| [assembled-reference.3mf](assembled-reference.3mf) | Figurine seated on the named base; separate the pieces before printing |

Both bases use 5.00 mm pegs, spaced 23 mm apart. The fit is slightly loose; see the [joint dimensions](../docs/PRINTING.md#joint-and-assembly).

Use `base-plain.3mf` for a blank front. Deleting the lettering from the named base leaves letter-shaped recesses.
